# Social Media Usage Analysis | Power BI

## Project Overview
This project analyzes social media usage patterns and their potential relationship with sleep, academic performance, and lifestyle habits. An interactive Power BI dashboard helps users explore usage trends across platforms, devices, and demographic groups.

## Objectives
- Analyze average daily social media usage.
- Compare usage patterns across different platforms.
- Understand weekday and weekend usage differences.
- Explore the relationship between social media usage and sleep duration.
- Analyze late-night usage and sleep quality.
- Compare usage across devices, gender, and academic levels.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Modeling and Data Visualization

## Dashboard Features
- KPI cards for average usage, weekend usage, average sleep, and late-night usage percentage.
- Platform-wise usage comparisons.
- Weekend usage analysis.
- Late-night usage analysis.
- Sleep quality distribution.
- Device-wise average usage.
- Interactive slicers for platform, gender, academic level, and device.

## Key Skills Demonstrated
- Data cleaning and transformation
- DAX measure creation
- KPI development
- Interactive dashboard design
- Trend analysis and comparative analysis
- Business insights from data

## How to View the Project
1. Download the `social media.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the slicers and visuals to explore the data.

This project demonstrates how Power BI can be used to analyze social media usage patterns and explore associations between digital habits, sleep, and academic performance.
